# MUSE/TUNES — Creator Pack 1

A self-contained local landing page and original kids-music pack for creators. It includes 5 tunes, 15 MP3 cuts, transparent character assets, documentation, and reproducible build scripts.

## Run locally

Open `creator-pack-1.html` in a browser from this folder. Keep `tunes/` and `assets/` beside it. The page has a playable bottom audio bar and a dark animated ink-ribbon background. It intentionally uses no orbital rings or orbit visual.

## Contents

- `creator-pack-1.html` — landing page
- `tunes/` — 15 generated MP3 files
- `assets/` — transparent PNG/GIF/APNG assets
- `LICENSE.txt` — plain-language use license
- `docs/` — FAQ, pricing, usage, and license explanations
- `scripts/` — local generation/build notes
- `space/` — notes for any future static host; no hosted Manus site is included

## Important

This ZIP is a local file package. No repository or hosted URL was created.
